# Data

`player_mvp_stats.csv` — one row per player and season, NBA seasons 1991–2021 (14 092 rows):
per-game stats, team record and MVP voting (`Pts Won`, `Pts Max`, `Share`).

Source: [dataquestio/project-walkthroughs — mvp](https://github.com/dataquestio/project-walkthroughs/tree/master/mvp),
built from [Basketball-Reference](https://www.basketball-reference.com/). Included unchanged for
educational use; the original repository does not state a license, so the data is **not** covered by
this project's MIT license.
